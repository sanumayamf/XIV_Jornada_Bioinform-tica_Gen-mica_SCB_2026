# XIV_Jornada_Bioinformàtica_&_Genòmica_SCB_2026
* This repository contains the code and bibliography used for the poster: "Mouse endogenous retroviruses exhibit higher protein-domain HMM coverage than humans" presented in the XIV Jornada Bioinformàtica & Genòmica organised by the Soceitat Catalana de Biologia (SCB) during December 2026.
* The project was carried out in the Centre Nacional d'Anàlasis Genòmica(CNAG) facilities within the HERVarium project, https://hervarium.cnag.eu.
