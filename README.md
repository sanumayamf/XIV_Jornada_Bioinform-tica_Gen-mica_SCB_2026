# Mouse endogenous retroviruses exhibit higher protein-domain HMM coverage than humans

This repository contains the code and bibliography used for the poster *"Mouse endogenous retroviruses exhibit higher protein-domain HMM coverage than humans"*, presented at the XIV Jornada de Bioinformàtica i Genòmica organised by the Societat Catalana de Biologia (SCB) in December 2026.

The project was carried out at the Centre Nacional d'Anàlisi Genòmica (CNAG) as part of the HERVarium project (https://hervarium.cnag.eu).

## Overview

Endogenous retroviruses (ERVs) are remnants of ancient retroviral infections that make up a substantial fraction of mammalian genomes. In this project, we compared how completely retroviral protein domains are preserved in human and mouse ERVs. For each domain hit, we measured its alignment coverage relative to the reference domain HMM and compared both species across seven canonical domain types (AP, DUT, ENV, GAG, INT, RNaseH and RT).

## Input data

The analysis uses four files, which must be placed in `data/`:

| File | Content |
|---|---|
| `HERV_internal_v5.bed` | Internal regions of human ERV loci |
| `ERV_mouse_internal.bed` | Internal regions of mouse ERV loci |
| `HERV_loci_annotated_domains.tsv` | Protein-domain hits in human ERV loci |
| `ERV_mouse_loci_annotated_domain.tsv` | Protein-domain hits in mouse ERV loci |

* Human annotation used:  https://zenodo.org/records/17662456/files/HERV_loci_annotated_domains_v5.tsv?download=1
* Mouse annotation used: https://zenodo.org/records/17752474/files/ERV_mouse_loci_annotated_domain.tsv?download=1 


## Requirements

- R version 4.6.1 
- R packages: `tidyverse`, `ggpubr`, `patchwork`

```r
install.packages(c("tidyverse", "ggpubr", "patchwork", "scales", "rmarkdown"))
```

## How to run

1. Clone this repository and place the input files in `data/`.
2. Open `poster1_script.Rmd` in RStudio (ideally from an RStudio project in this folder, so that relative paths work).
3. Click **Knit**. The figures will be saved in `figures/`.
